[Rafa's Marketplace](https://github.com/erdos2n/rafas-marketplace) is my collection of free Claude Code plugins and skills.

## Install in Claude Code

```bash
claude plugin marketplace add erdos2n/rafas-marketplace
```

Then browse and install plugins with `/plugin`.

See the [repo](https://github.com/erdos2n/rafas-marketplace) for what's available and how each one works.
